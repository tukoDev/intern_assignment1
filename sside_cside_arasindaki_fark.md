Sunucu tarafı ve istemci tarafı programlama, web geliştirmenin iki temel bileşenidir ve farklı yerlerde çalışan, farklı sorumlulukları olan kod türleridir.



#### İstemci Tarafı (Client-Side) Programlama

İstemci tarafı programlama, kullanıcının cihazında (tarayıcı, mobil uygulama vb.) çalışan kodları ifade eder. Bu kodlar kullanıcının cihazına indirilir ve orada yürütülür.



**Temel Özellikleri:**

* Kod doğrudan kullanıcının tarayıcısında veya uygulamasında çalışır
* Kullanıcı arayüzü ve etkileşimlerden sorumludur
* Anında tepki verebilir (gerçek zamanlı etkileşim)
* Sunucuya sürekli bağlantı gerektirmez
* Kaynak kodları kullanıcı tarafından görülebilir



**Kullanılan Teknolojiler:**

* HTML, CSS, JavaScript
* React, Vue.js, Angular gibi framework'ler
* TypeScript
* WebAssembly
* Mobil için Swift, Kotlin, React Native, Flutter



**Avantajları:**

* Hızlı kullanıcı deneyimi (anlık tepki)
* Sunucu yükünü azaltır
* Çevrimdışı çalışabilir
* Etkileşimli arayüzler oluşturabilir



**Dezavantajları:**

* Güvenlik riski (kod görülebilir)
* Farklı tarayıcılarda uyumluluk sorunları
* Cihaz performansına bağımlı
* Hassas işlemler için güvenilir değil



#### Sunucu Tarafı (Server-Side) Programlama

Sunucu tarafı programlama, web sunucusunda çalışan ve kullanıcı isteklerine yanıt veren kodları ifade eder. Bu kodlar sunucuda yürütülür ve sonuçları istemciye gönderilir.



**Temel Özellikleri:**

* Kod sunucuda çalışır, sonuç istemciye gönderilir
* Veri işleme, depolama ve güvenlik işlemlerinden sorumludur
* Veritabanı bağlantıları yönetir
* Kullanıcı kimlik doğrulama ve yetkilendirme işlemleri
* Kaynak kodları kullanıcıdan gizlidir



**Kullanılan Teknolojiler:**

* Node.js (JavaScript)
* Python (Django, Flask, FastAPI)
* Java (Spring Boot)
* C# (.NET)
* PHP (Laravel, Symfony)
* Ruby (Ruby on Rails)
* Go, Rust



**Avantajları:**

* Güvenli (kod gizli kalır)
* Güçlü işlem kapasitesi
* Merkezi veri yönetimi
* Tutarlı performans
* Hassas iş mantığı için güvenilir



**Dezavantajları:**

* Ağ gecikmesi (network latency)
* Sunucu kaynaklarına bağımlılık
* İnternet bağlantısı gerektirir
* Ölçeklenebilirlik maliyeti





#### PHP NEDEN BACKEND DİLİDİR?

PHP backend dilidir çünkü tarayıcılar PHP kodlarını çalıştıramaz, sadece web sunucuları çalıştırabilir.

PHP kodlari web sunucusunda işlenir ve sonuçları HTML olarak tarayıcıya gönderir, bu yüzden kullanıcılar hiçbir zaman php kodlarını göremez.

Ayrica PHP veritabani bağlantıları, dosya işlemleri ve sistem kaynaklarına erişim gibi sunucu taraflı işlemler için tasarlanmıştır.

Frontend dil olan JavaScriptin aksine PHP daha güvenli bir şekilde bilgileri işleyebilir ve sunucu kaynaklarını yönetebilir.
